## Fragmented Curated FMN Riboswitch

**data/fragmented_fmn/cluster_57_1.cm** built from **data/fragmented_fmn/cluster_57_1.cacofold.R2R.sto** using cmbuild and cmcalibrate as described below, see file for exact parameters.
Similarly **data/fragmented_fmn/cluster_35_1.cm** built from **data/fragmented_fmn/cluster_35_1.cacofold.R2R.sto**

data/fragmented_fmn/cluster_57_1.cacofold.R2R.sto is an alignment from r-scape run as described below.

```bash
wget https://ftp.ebi.ac.uk/pub/databases/Rfam/15.1/fasta_files/RF00050.fa.gz

gunzip RF00050.fa.gz 

mmseqs createdb RF00050.fa mmseqsdb/RF0050.db

mmseqs cluster mmseqsdb/RF0050.db outclusterdb/RF0050.db temp  --min-seq-id 0.25 -c 0.2 --cov-mode 3 --cluster-mode 1 -s 7.5

mmseqs createtsv mmseqsdb/RF0050.db mmseqsdb/RF0050.db outclusterdb/RF0050.db outputclustertbl.tsv

python ../DarwinsRNAHunt/workflow/src/extract_cluster_nucleotide_fasta.py    --fasta RF00050.fa --clusters outputclustertbl.tsv
            --cluster_id '{wildcards.cluster_id}' \
            --output {output.cluster_fasta} \
            2>&1 | tee {log}
```

See [DarwinsRNAHunt](https://github.com/dan-432/DarwinsRNAHunt) for extract_cluster_nucleotide_fasta.py script

Then aligned with maftt, ran r-scape, built cm with cmbuild as in the [DarwinsRNAHunt](https://github.com/dan-432/DarwinsRNAHunt) pipeline.

Cluster covariance models were then scored against the "true" RF00050 covariance model (sourced from [rfam.org](https://rfam.org) ([https://ftp.ebi.ac.uk/pub/databases/Rfam/](https://ftp.ebi.ac.uk/pub/databases/Rfam/) on 03/08/2026), Rfam v15.1) with [cm-simile](https://github.com/dan-432/cm-simile), also developed by me as a part of this project.
Of all covariance models build from the above method, **data/fragmented_fmn/cluster_57_1.cm** scored best against RF00050 based on $$ks D_[a_into_b]$$ and $$ks D_[a_into_b]$$, and $$median_a_into_b$$ and $$median_b_into_a$$ bitscores, again see [cm-simile](https://github.com/dan-432/cm-simile).
**data/fragmented_fmn/cluster_35_1.cm** has a weaker similarity score to RF00050.
